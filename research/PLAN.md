## 3. Принципы честной проверки

* **Разделение на обучение и финальную проверку пока не фиксируем:** сначала докачиваем все
  данные (06z/18z, прогнозные признаки, Previous Runs с 2024 года). Тогда выберем период для
  финальной проверки, который **не трогаем** при подборе модели, и проверим на нём один раз
  заранее записанное правило.
* Текущие результаты (B0–B2.1) — **снимок методологии** на апрель–октябрь 2026; переделываем по мере
  поступления данных.
* Исполнение в бэктестах: цены реальных сделок других тейкеров после момента решения
  (приближение). Настоящие цены и глубина — по логгеру стакана, когда наберётся запись.
* Значимость: t с кластеризацией по город-дню; помнить о множественных проверках.

## 7. Ключевые знания (кратко; подробно в FINDINGS §1–§3, SOTA)

* **Резолв.** Три режима правил Polymarket: WU (до 22.08.2026) → NOAA timeseries
  (23.08–22.10) → **aviationweather METAR, только routine, SPECI не считаются, T-группа или целые °C,
  half-up, для США °F** (с 23.10). Гонконг — HKO. Резолвер совпадает с исходами: AWC 100 %,
  NOAA 99.0 %, WU 98.2 % (§6). **Метка для модели — фактически засчитанный бакет.**
* **Комиссия** тейкера `0.05·p·(1−p)` за акцию с апреля 2026, мейкер без комиссии + ребейт.
* **Задержки публикации METAR** на aviationweather: медиана ~5 мин, по городам 0.4–30 мин (§9).
* **Open-Meteo Single Runs** доступны с 2026-04-02 (JMA с 05-13, GEM с 08-19), похоже,
  скользящее окно. Бесплатный тариф — для некоммерческого использования (исследование, paper).
* **ICON** — лучшая отдельная модель для этих станций, но смесь моделей лучше любой одной.
* **Аудит старого кода** (ошибки методологии, Нарита вместо Ханэды, неисполнявшиеся выходы
  и т.д.) — в истории этого файла (коммит `927d740`) и в первом разборе сессии.
