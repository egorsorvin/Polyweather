## 1. Главные инсайты (кандидаты в вклад статьи)

1. **Рынок эффективен вплоть до задержки информации.**
   * Цены откалиброваны: отклонения ~1 п.п. на ~100 тыс. снимков (FINDINGS §4).
   * Рынок точнее постпроцессинга NWP: EMOS по 6–8 моделям уступает ~7.5 % по Brier,
     единая as-of модель (B2.1) ~15 % (§14, §15).
   * Единственный устойчивый edge — **латентность**: в США рынок ждёт часовой METAR,
     минутные наблюдения дают +3–5 % (t ≈ 3.5), edge тает с задержкой (§12). Там, где METAR
     получасовой и есть быстрые национальные потоки (Токио, Сеул), рынок реагирует за 1–3 мин,
     и edge нет (§9, §13).
   * Прямое измерение скорости, с которой физический факт попадает в цену, по городам и
     правилам резолва.
   * Ценность: рынок с **физически проверяемым исходом** — редкий случай, когда вероятность
     можно сверить с реальностью.
2. **Рынок как сильный вероятностный бейзлайн для ML и NWP.** Когда модель добавляет
   информацию к цене (лог-пул рынок + модель), в зависимости от горизонта, признаков и
   источника данных.
3. **Ловушки бэктестов против рынков** (методологический вклад):
   * утечка из будущего через `previous_day1` у Open-Meteo;
   * артефакт устаревшей цены: +8.7 % по последней сделке против −1.8 % по реальным
     сделкам (§11);
   * смена правил резолва и станций (§6, SOTA);
   * завышенная значимость без кластеризации по дням, множественные проверки;
   * переуверенность бустинга на почти дублирующихся состояниях (§15).
4. **Датасет / бенчмарк** «PolyWeather-Bench» (см. §3).

## 3. Датасет / бенчмарк (что войдёт)

* События и бакеты Polymarket «highest temperature», 53 города, 2025-01 → (12.8 тыс. событий).
* Исходы + **точный таргет по правилам резолва** каждого периода (резолвер, §6).
* Ленты сделок (29 млн) и, с ноября 2026, **стакан** (логгер).
* Прогнозы 8 NWP/AI-моделей **как были опубликованы** (Open-Meteo Single Runs), as-of выборка.
* METAR (routine / SPECI), 1-мин ASOS (США), JMA 10-мин, NEA 1-мин.
* Задача: для момента t выдать распределение по градусам; метрики: Brier / log-loss / RPS
  против рынка в тот же момент, плюс честный торговый бэктест.
* **Проверить права на распространение:** условия Polymarket, Open-Meteo (CC BY 4.0 —
  уточнить для Single Runs), IEM, JMA, NEA. Сделки публичны в блокчейне, но лучше уточнить.

## 7. Итоги обзора новизны (6 ноября 2026, `paper/novelty_review.md`)

* **ML-новизны в виде архитектуры нет.** Ценность: инфраструктура (точный по правилам таргет,
  53 города, 29 млн сделок), внешний бенчмарк с реальными деньгами для AI-моделей погоды и
  естественный эксперимент о латентности.
* **Ближайший предшественник — Crosier (arXiv 2609.23969):** Kalshi, 7 городов США, рынок
  точнее NBM на ~10–11 % по RMSE. Наш результат «модель хуже рынка» сам по себе его повторяет;
  отличие: Polymarket, весь мир, вероятностные метрики по бакетам, точный таргет, AI-модели,
  латентность.
* **Свободная ниша:** не найдено событийного исследования реакции цен Kalshi / Polymarket на
  публикацию данных (METAR, прогоны моделей) с разрешением в минуты и секунды.
* **Слабое место:** из AI-моделей у нас только AIFS Single. Нужны AIFS-ENS, AIGEFS / HGEFS
  (NOAA), WeatherNext 2, GraphCast-подобные, а для США — NBM.

Варианты статьи (по новизне × реализуемости):
1. **Латентность наблюдений и ценообразование** — самое новое, данные почти есть
   (+ стакан из логгера). IJF, ICAIF, q-fin. Риск: раскрытие собственного edge.
2. **Бенчмарк AI/NWP против рынка с точным таргетом** — NeurIPS E&D, TMLR, Met Apps.
   Риск: пересечение с Crosier, короткая история Single Runs, условия Polymarket на данные.
3. **Ловушки бэктеста** — скорее раздел / приложение к 1 и 2.

Практика: arXiv с 2026 года требует endorsement для первой подачи; TMLR оценивает
доказанность, а не новизну; IJF проверяет воспроизводимость; данные Polymarket — публиковать
производные и скрипты повторной выгрузки; раздел о конфликте интересов.
Дополнительные эксперименты (E11–E13): AI-ансамбли и NBM как бейзлайны; событийное
исследование латентности по прогонам и METAR на минутном / секундном разрешении;
прочитать Crosier целиком и найти цитирующие его работы.
